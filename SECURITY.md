# Security

boring-crocodile handles sign-in, accounts and command execution on your host, so please report a security problem
privately, not as a public issue: on GitHub, **Security → Report a
vulnerability** in this repository (a private thread with the maintainer).

Say what you found, how to reproduce it, and which release you looked at.

Only the latest release gets fixes. This is a small project maintained for
its own use: expect an acknowledgement within a few days, and a fix in the
next release. If you like, you are credited in the CHANGELOG.
